# Curve Tab Folders 0.1.0

Curve’s sidebar folder behavior, now a separately installed module for Search.

**Requires Search Appearance Mod Loader 0.3.0 or newer.** Download the updated loader from https://github.com/haon-v2/search-appearance-mods/releases/latest, then import `curve-tab-folders.json` in Settings → Appearance and Enable it. Unmodified official Search cannot load it yet.

Includes collapsible folders, bold names and right-side disclosure arrows, drag-to-folder, tab context-menu moves, hover-only dotted guides, per-space persistence, folder-scoped curved tabs, and Curve JSON import/export. Imported tabs stay asleep until selected. Disabling the module keeps your folders and tabs saved.

This module is **separate from Curve Tabs**. Either can be used alone, or both together with the sidebar enabled.

Full credit for Search belongs to **Drice Roland / Office Commun and its contributors**. Noah Helms contributed the folder port, optional module, and supporting loader capability. This is an unofficial community contribution.

The preview uses its own profile: first-time users switching from official Search should expect to log in again. Existing preview upgrades retain their profile. Seamless official integration would require Drice / Office Commun to ship the loader in Search.
